ASSET GUIDE
===========

Optional profile photo
----------------------
1. Put your image in this folder, for example:
   assets/profile.jpg
2. In config.js set:
   profileImage: "assets/profile.jpg"

Recommended profile image:
- Portrait orientation
- Around 900 x 1100 px
- JPG, PNG or WebP
- Keep the file reasonably compressed for fast loading

Resume
------
The template includes assets/resume.pdf so the download button works immediately.
Replace that file with your actual resume and keep the same filename.

Project screenshots
-------------------
You can add images such as:
  assets/project-support-hub.webp

Then set the image property for that project in config.js:
  image: "assets/project-support-hub.webp"

If image is left blank, the template automatically shows a generated visual instead.
